# Getting Support for NgDesktop Engine

Welcome! Before opening an issue, please check the resources below so your question reaches the right place quickly:

## 📚 Documentation & Guides

- **Overview, Architecture & Quick Start:** [`README.md`](./README.md)
- **Technical Roadmap & Design History:** [`ROADMAP.md`](./ROADMAP.md)
- **Version History & Release Notes:** [`CHANGELOG.md`](./CHANGELOG.md)
- **Contributing Guide & Coding Standards:** [`CONTRIBUTING.md`](./CONTRIBUTING.md)

## 🧭 Where to File What

| Need                                                           | Action                                                                                                                                             |
| :------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Found a bug or crash?**                                      | Open a [Bug Report](https://github.com/Gaspar1992/ng-desktop-engine/issues/new?template=bug_report.yml)                                            |
| **Proposing a new Angular API or native widget?**              | Open a [Feature Request](https://github.com/Gaspar1992/ng-desktop-engine/issues/new?template=feature_request.yml)                                  |
| **Reporting a Windows/macOS/Linux parity gap?**                | Open a [Cross-Platform Parity Issue](https://github.com/Gaspar1992/ng-desktop-engine/issues/new?template=platform_parity.yml)                      |
| **Reporting a security vulnerability?**                        | Submit a [Private Security Advisory](https://github.com/Gaspar1992/ng-desktop-engine/security/advisories/new) (see [`SECURITY.md`](./SECURITY.md)) |
| **Downloading `.deb`, `.exe`, `.dmg`, or `@ng-native/*.tgz`?** | Visit the [GitHub Releases Page](https://github.com/Gaspar1992/ng-desktop-engine/releases)                                                         |
